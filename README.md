# نظام إدارة الصيدلية — النسخة الأولية

واجهة عربية RTL لإدارة الأصناف والفواتير والنواقص ومقارنة الأسعار، تعمل محلياً في المتصفح باستخدام IndexedDB.

## التشغيل
- افتح `index.html` في متصفح حديث أو ارفع المجلد إلى GitHub Pages.
- اتصال الإنترنت مطلوب لتحميل مكتبة SheetJS من CDN عند استيراد Excel.
- البيانات تبقى في IndexedDB داخل المتصفح والجهاز الحالي.

## الوظائف الموجودة في هذه النسخة
- لوحة تحكم وإحصاءات أساسية.
- إضافة الأصناف مع وحدة الشراء والوحدة الأساسية ومعامل التحويل.
- استيراد ملفات XLS/XLSX مع محاولة اكتشاف جدول الأصناف.
- معاينة الفاتورة قبل الاعتماد ومنع تكرار الفاتورة وفق بصمة أولية.
- حفظ الكمية والسعر والبونص والخصم والتشغيلة والانتهاء.
- حساب السعر الفعلي بعد البونص.
- إدارة النواقص مع منع تكرار الصنف النشط.
- مقارنة الأسعار حسب السعر الأصلي أو السعر الفعلي بعد البونص.
- دليل الموردين وسجل المشتريات.
- تصدير واستعادة نسخة JSON.

## حدود النسخة الحالية
هذه نقطة انطلاق قابلة للتطوير وليست إصداراً إنتاجياً نهائياً:
- محلل Excel يعتمد على أسماء أعمدة شائعة؛ يلزم اختبار عينات فعلية متعددة، وإضافة قوالب للمصادر المختلفة.
- يجب تطوير مطابقة الأصناف الذكية، ومطابقة المشتريات مع النواقص، وتجميع الطلبيات والطباعة المتقدمة.
- بصمة منع التكرار أولية؛ الأفضل اعتماد رقم المورد ورقم الفاتورة وتاريخها مع مراجعة التعارضات.
- لا توجد مزامنة بين الأجهزة أو تعدد مستخدمين أو صلاحيات.
- لا يوجد تشفير للبيانات المحلية.
- استيراد Excel يعتمد على SheetJS عبر CDN؛ للاستعمال دون إنترنت يجب تضمين المكتبة محلياً.
- يجب مراجعة تحويل الوحدات قبل مقارنة أسعار أصناف من وحدات مختلفة. معامل التحويل محفوظ في الصنف لكنه لم يطبق بعد على كل عمليات التسعير.
- لا تعتمد النسخة على بيانات فعلية حساسة قبل الاختبار والنسخ الاحتياطي.

## التقنية
HTML5 + CSS + JavaScript + IndexedDB + SheetJS.
